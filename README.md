# 8051 Assembly Counter

## Description

This repository contains examples of Assembly programs for the **8051 microcontroller**, implementing a decimal counter that displays values on a digital display. It is a study project for **Computer Architecture**, demonstrating concepts such as **BCD manipulation, subroutines, stack usage, and display control**.

The program counts from **00 to 99 in decimal**, using BCD adjustment and displaying the digits on **7-segment displays**.

---

## Files

- `contador.A51`: Initial version of the counter program.  
- `contador_v2.A51`: Version 2 with possible improvements or variations.  
- `contador_v3.A51`: Version 3.  
- `*.LNK`: Link files generated by the assembler.  
- `*.LST`: Listing files containing assembly code and memory addresses.  
- `*.p51`: Object or HEX output files generated during compilation.

---

## Requirements

- An **8051-compatible assembler**, such as **ASEM-51** or **Keil µVision**.  
- An **8051 simulator** (such as Proteus or an online simulator) or a **physical development board** to test the program.

---

## How to Compile

1. Install an 8051 assembler.  
2. Run the compilation command for the desired `.A51` file.

Example using ASEM-51:

```bash
asem contador.A51
